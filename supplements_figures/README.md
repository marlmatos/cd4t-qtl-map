# Supplementary figures

R Notebooks and scripts generating supplementary figures and QC plots for the manuscript.

## Contents
- `supplements_1.Rmd` — Supplemental Figure 1 (cohort composition, genotype PCA)
- `supplements_1_atacseq.Rmd` — ATAC-seq-specific supplemental QC figures
- `supplements_1.nb.html` / `supplements_1_atacseq.nb.html` — corresponding knitted HTML notebooks
- `atac_library_size_distribution.R` — ATAC-seq library size distribution plots
- `atac_library_scaled_regions_tss_tes.R` — ATAC-seq signal over scaled gene bodies (TSS–TES)
- `scrnaseq_library_stats.R` — scRNA-seq library QC statistics
- `data_sppl1/` — supporting data (e.g. `all_samples_gencove_ancestry.json`) used by the notebooks above
